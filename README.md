# Depression Severity Detection Pipeline

A two-tier cascade system for classifying depression severity in social media posts, based on the [DSD dataset](https://huggingface.co/datasets/). Labels follow PHQ-9 aligned severity levels: **minimal → mild → moderate → severe**.

---

## How It Works

```
All posts → [Tier 1: DistilRoBERTa Filter] → flagged posts → [Tier 2: Llama 3.1-8B QLoRA] → severity label
                      low threshold (0.3)                         chain-of-thought reasoning
```

**Tier 1** is a lightweight binary classifier that acts as a sentinel — it scores every post for depressive content and forwards anything above the threshold to Tier 2. The threshold is kept low (0.3) so that severe cases are almost never dropped at this stage.

**Tier 2** is a QLoRA fine-tuned Llama 3.1-8B-Instruct model that performs chain-of-thought clinical reasoning to assign one of the four severity labels to each post that passed Tier 1.

## Dataset Format

`data/dsd.csv` must have two columns:

| column | description |
|--------|-------------|
| `text`  | Raw social media post (string) |
| `label` | One of: `minimal`, `mild`, `moderate`, `severe` (also accepts `minimum`) |

**Sample data:**

```csv
text,label
"I've been feeling really low lately, can't seem to find joy in anything I used to love. Work feels pointless.",moderate
"Just had the best weekend hiking with friends. Feeling refreshed and motivated for the week ahead!",minimal
"Everything feels hopeless. I haven't left my bed in three days and I don't see the point anymore.",severe
"Had a rough few days, feeling a bit stressed about deadlines but I know it'll pass.",mild
"Can't stop crying and I don't even know why. Called in sick again. Third time this month.",moderate
"Went grocery shopping, cooked dinner, watched a show. Pretty normal day overall.",minimal
"I've been thinking about how much easier it would be if I just wasn't here anymore.",severe
"Feeling a little burnt out from work this week. Looking forward to the weekend.",mild
```

**Approximate class distribution in the full DSD dataset:**

| label    | share  |
|----------|--------|
| minimal  | ~72.8% |
| mild     | ~11.0% |
| moderate | ~8.3%  |
| severe   | ~7.9%  |

The heavy class imbalance is handled by `WeightedRandomSampler` during fine-tuning and by keeping the Tier 1 threshold low to avoid dropping minority-class posts.

## Setup

```bash
pip install -r requirements.txt
```

`requirements.txt` pins PyTorch to the CUDA 12.1 build (`+cu121`), compatible with RTX 30xx/40xx cards. If you're on a different CUDA version, update the `+cu121` suffix and the `--extra-index-url` line accordingly — see [pytorch.org/get-started](https://pytorch.org/get-started/locally/) for the right combination.

Tier 2 fine-tuning and inference require a CUDA GPU with at least **12 GB VRAM** (tested on RTX 3080/4080 and A100). Tier 1 runs on CPU if no GPU is available.

You also need to be authenticated with Hugging Face to download Llama 3.1-8B-Instruct (gated model):

```bash
huggingface-cli login
```

## How to Run

All pipeline settings are in the `CONFIG` dict at the top of `main.py`.

### Step 1 — Test Tier 1 and generate data splits

Set `"skip_tier2": True` in `CONFIG`, then:

```bash
python main.py
```

This loads `data/dsd.csv`, produces stratified `data/train.csv` and `data/test.csv`, runs the Tier 1 filter over the test set, and prints System Recall (% of severe posts retained).

### Step 2 — Fine-tune the Tier 2 LLM

Requires a CUDA GPU. Reads `data/train.csv` produced in Step 1.

```bash
python -m src.tier2_finetune
```

Saves the QLoRA adapter to `models/tier2_adapter/`. Training takes ~1–2 hours on a single consumer GPU (RTX 3080) with the default 2-epoch config.

### Step 3 — Run the full pipeline

Set `"skip_tier2": False` in `CONFIG`, then:

```bash
python main.py
```

Results are saved to `data/final_results.csv` with columns: `text`, `label`, `tier1_score`, `tier2_label`, `tier2_reasoning`.

## Configuration Reference

All options are in the `CONFIG` dict in `main.py`:

| key | default | description |
|-----|---------|-------------|
| `data_path` | `data/dsd.csv` | Path to the input CSV |
| `output_path` | `data/final_results.csv` | Path for Tier 2 output |
| `test_size` | `0.2` | Fraction of data held out for evaluation |
| `tier1_model` | `mrm8488/distilroberta-base-finetuned-suicide-depression` | HuggingFace model ID for Tier 1 |
| `threshold` | `0.3` | Tier 1 pass threshold (lower = more posts forwarded to Tier 2) |
| `adapter_path` | `models/tier2_adapter` | Path to the QLoRA adapter directory |
| `skip_tier2` | `False` | Set `True` to stop after Tier 1 |

## Evaluation Metrics

| metric | what it measures |
|--------|-----------------|
| **System Recall** | % of `severe` posts retained by Tier 1. Primary safety metric — should stay as high as possible. |
| **Macro F1** | Tier 2 F1 averaged equally across all 4 classes. Penalises failures on minority classes. |
| **Weighted F1** | Tier 2 F1 weighted by class frequency. Reflects overall accuracy given the imbalance. |
| **Ordinal MAE** | Mean absolute error on the severity ordering (minimal=0, mild=1, moderate=2, severe=3). Penalises distant misclassifications more than adjacent ones. |
